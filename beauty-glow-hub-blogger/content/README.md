# Beauty Glow Hub — Content Pack + AdSense Setup Guide

This pack gives you a **complete, ready-to-publish beauty blog**: 8 legal/trust
pages and 26 human-written beauty articles (with images) — everything you
need for Google AdSense approval.

You have **two ways** to add it all. Method A is the fastest.

---

## ✅ Method A — Import everything at once (recommended)

1. In Blogger, go to **Settings → Manage blog → Import content**.
2. Upload **`beauty-glow-hub-content.xml`**.
3. Tick **"Automatically publish all imported posts and pages"** and confirm the captcha.
4. Done — all 6 posts and 8 pages are now published. 🎉

> If Blogger ever refuses the import, just use Method B for any items — it always works.

## ✅ Method B — Paste each one (100% reliable)

**Posts:** Blogger → **New post** → click the **pencil ▾ → HTML view** → open a file
from `content/posts/` → copy everything → paste → add a **Title** and **Labels**
(shown below) → **Publish**.

**Pages:** Blogger → **Pages → New page** → **HTML view** → paste a file from
`content/pages/` → add the Title → **Publish**.

## After publishing — finish the setup

1. **Menu:** Layout → the Navigation widget → add your Pages (Home, Skin Care,
   Hair Care, About, Contact…). Labels also work as menu links, e.g.
   `/search/label/Skin Care`.
2. **Footer legal links:** Layout → footer "Company" link list → add About,
   Contact, Privacy Policy, Disclaimer, Affiliate Disclosure, Terms, DMCA.
3. **Contact page:** open the Contact page and replace `hello@yourdomain.com`
   with your real email (in the form and the text).
4. **Your details:** Settings → Title & Description; upload a logo in Layout → Header.

## Images

The article images are hosted on GitHub and load automatically, so your blog

re-upload each image inside the Blogger post editor later — the image files are
in the `images/` folder.

## 🎯 Google AdSense Approval Checklist

- [x] **Privacy Policy** page (required — mentions Google/AdSense cookies) ✔ included
- [x] **About** page with a real description ✔ included
- [x] **Contact** page with a real email/form ✔ included
- [x] **Disclaimer**, **Terms**, **Affiliate Disclosure**, **Editorial Policy**, **DMCA** ✔ included
- [x] **Original, useful content** — 26 in-depth articles ✔ included (great for applying; keep adding more)
- [x] **Clear navigation menu** and footer links
- [x] **Fast, mobile-friendly, no broken links** ✔ (the theme handles this)
- [ ] **Custom domain** (optional but helps): connect a `.com` in Settings
- [ ] **Enough content & a little age:** publish 15–20 posts and wait ~2–4 weeks of activity before applying
- [ ] Apply at **adsense.google.com**, then paste your Publisher ID / ad code into the theme's ad slots (Layout → HTML/Advertisement widgets)

**Tip:** Keep publishing 2–3 posts a week. Fresh, original, helpful content is
the single biggest factor in getting approved and staying approved.
