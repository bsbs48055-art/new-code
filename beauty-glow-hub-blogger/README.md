# Beauty Glow Hub — Blogger (Blogspot) Theme

A premium, magazine-style **Blogger** template for a beauty, skincare, hair care,
makeup and wellness blog. It is content-first, fast, responsive, SEO-friendly and
AdSense-ready — the Blogger version of the Beauty Glow Hub design.

**File to upload:** `beauty-glow-hub.xml`

---

## How to Install (2 minutes)

1. Download **`beauty-glow-hub.xml`** to your computer.
2. Sign in to **[blogger.com](https://www.blogger.com)** and open your blog.
3. In the left menu, go to **Theme**.
4. Click the **arrow (⌄) next to "Customize"** → **Restore**.
5. Click **Upload**, choose the `beauty-glow-hub.xml` file, and confirm.
6. Done! Visit your blog to see the new design.

> Tip: Before uploading, click **Theme → ⌄ → Backup** to save your current theme first.

## After Installing — Quick Setup

Everything works out of the box, but to make it yours:

- **Menu:** Go to **Layout → PageList (Navigation)** and add your Pages, or **Pages → New page** to create About, Contact, Privacy Policy, etc. They appear in the top menu automatically.
- **Logo / Title:** **Layout → Header** — add a logo image or keep the text title. Set your blog description in **Settings → Description** (shows under the title).
- **Social links:** These are in the top bar. Edit **Theme → ⌄ → Edit HTML**, search for `bgh-social`, and replace the `href='#'` values with your Facebook / Instagram / Pinterest / X URLs.
- **Ads (AdSense):** In **Layout**, use the "Advertisement" HTML widgets in the **header** and **in-article** areas — paste your AdSense code there. Placeholders show until you add code.
- **Sidebar:** **Layout → Sidebar** lets you add/reorder Search, Popular Posts, Labels (categories), Newsletter and more.
- **Footer:** **Layout → footer columns** — add your link lists and text.
- **Comments:** Native Blogger comments are enabled (**Settings → Comments**).

## Features

- Magazine homepage with post cards, category chips and featured images
- Single post layout with breadcrumbs, author box, tags, social share
- **Automatic Table of Contents** and **reading time** (built with lightweight JS)
- **Related posts** by label
- Popular posts, labels, search and newsletter widgets
- Responsive mobile menu, back-to-top button
- SEO: Open Graph tags + Organization/WebSite JSON-LD schema
- AdSense-ready ad zones (header + in-article)
- Palette `#E91E63 / #F8BBD0 / #D4AF37`, fonts Playfair Display + Inter

## Notes

- This is a **Blogger** theme (single XML). It is **not** a WordPress theme.
- Requires the modern Blogger theme engine (all current Blogger blogs support it).
- Category = Blogger **Label**. Add labels to posts to populate categories and related posts.
